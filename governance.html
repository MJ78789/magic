Metadata ขั้นต่ำ

Author, reviewer, published/updated date, status, sources, checked date, risk category, review due date และ change summary

Quality gate

แยกข้อเท็จจริงจากคำแนะนำ ตรวจตัวเลข/ลิงก์/แหล่งอ้างอิง ไม่เติมข้อมูลที่ไม่มี และกำหนดผู้รับผิดชอบอนุมัติ

ความเสี่ยงสูง

การเงิน การลงทุน สุขภาพ กฎหมาย องค์กร และข้อมูลที่เปลี่ยนเร็วต้องมี reviewer และ disclaimer ก่อน Published

สถานะเนื้อหา

Draft → Review → Published → Update Required → Archived การแก้ไขสาระสำคัญต้องบันทึกวันที่ ผู้ตรวจ และ change summary

กฎเฉพาะ MVP

  • FAQ ชุดทบทวนปัจจุบันแสดงจำนวนจริง 60/180 และไม่อ้างว่าเสร็จ
  • PPRM ไม่ขยายคำเต็ม ไม่กำหนดเกณฑ์หรือคะแนนขององค์กรหากไม่มีเอกสารที่ได้รับอนุญาต
  • สินค้าไม่มี listing จนกว่าจะยืนยันร้าน URL ราคา สถานะ และ compliance
  • Analytics, revenue, conversion และ user count ต้องมาจาก provider จริงเท่านั้น
  • บทความเดิมถูกเก็บไว้; การเติม reviewer/source metadata ครบทุกบทความเป็นงานทบทวนแยก ไม่สร้างชื่อหรือแหล่งอ้างอิงแทน

แจ้งข้อมูลผิด

ช่องทางรับรายงานแบบมีฐานข้อมูลยังไม่เปิด ผู้ใช้สามารถแจ้งผ่านช่องทางสาธารณะจากหน้าแรกโดยระบุ URL ข้อความที่ควรตรวจ และแหล่งที่มา โดยไม่ส่งข้อมูลส่วนบุคคลอ่อนไหว
