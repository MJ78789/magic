# เริ่มใช้ Telegram สำหรับมือใหม่: ตั้งค่าบัญชี ความเป็นส่วนตัว และแชตแรก

Telegram เป็นแอปสื่อสารที่ใช้ได้ทั้งโทรศัพท์และคอมพิวเตอร์ ก่อนสนใจ bot หรือ automation ควรตั้งค่าบัญชีและความเป็นส่วนตัวให้เรียบร้อย

## เริ่มต้น

ติดตั้ง Telegram จากแหล่งทางการ สมัครด้วยหมายเลขโทรศัพท์และยืนยันรหัส ตั้งชื่อและรูปเท่าที่ต้องการ จากนั้นเปิด Settings > Privacy and Security ตรวจว่าใครเห็นหมายเลขโทรศัพท์ รูป เวลาออนไลน์ และใครเพิ่มเราเข้ากลุ่มได้

## ป้องกันบัญชี

เปิด Two-Step Verification ตั้งรหัสที่ไม่ซ้ำกับบริการอื่น และเพิ่มอีเมลกู้คืนที่เข้าถึงได้ ตรวจ Active Sessions เป็นระยะและปิด session ที่ไม่รู้จัก อย่าส่งรหัส OTP ให้ใคร แม้บุคคลนั้นอ้างว่าเป็นเจ้าหน้าที่

## เข้าใจพื้นที่สนทนา

แชตส่วนตัวเหมาะกับการคุยหนึ่งต่อหนึ่ง กลุ่มเหมาะกับสมาชิกหลายคน ช่องหรือ Channel เหมาะกับการประกาศ และ Topics ช่วยแยกเรื่องในกลุ่มที่เปิดใช้งาน อย่ากดลิงก์หรือดาวน์โหลดไฟล์จากคนไม่รู้จักโดยไม่ตรวจสอบ

## ตัวอย่างจัดกลุ่มงาน

สร้างกลุ่มทดลองหนึ่งกลุ่ม แยกหัวข้อ “ประกาศ”, “งานที่ต้องทำ” และ “คำถาม” กำหนดว่าเรื่องใดควรส่ง DM และเรื่องใดควรอยู่ในกลุ่ม เพื่อไม่ให้ข้อมูลส่วนตัวกระจายเกินจำเป็น

Checklist วันนี้คือ เปิด 2FA / ตรวจ Privacy / ตรวจ Active Sessions / ปักหมุดแชตสำคัญ / ปิด auto-download ที่ไม่จำเป็น / ไม่แชร์ token หรือ OTP

แหล่งข้อมูลทางการ: https://telegram.org/faq และ https://telegram.org/apps
