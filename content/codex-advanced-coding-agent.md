# Codex ขั้นสูงคืออะไร: จากผู้ช่วยเขียนโค้ดสู่ Agent ที่ทำงานครบวงจร

Codex คือ coding agent ของ OpenAI ที่อ่าน ทำความเข้าใจ แก้ไข ตรวจสอบ และดีบักโค้ดได้ จุดเด่นขั้นสูงไม่ใช่การเขียนโค้ดยาวที่สุด แต่คือการทำงานเป็นวงจร: รับเป้าหมาย อ่านบริบท วางแผน แก้ไฟล์ รันการตรวจ และรายงานสิ่งที่เปลี่ยนให้มนุษย์ทบทวน

## เลือกพื้นผิวให้เหมาะ

CLI เหมาะกับงานใน repository ผ่าน terminal, IDE extension เหมาะกับงานที่ต้องเห็นโค้ดขณะเขียน, แอปหรือ cloud เหมาะกับการวางแผน รีวิว และมอบงานที่ยาวขึ้น สิทธิ์เข้าถึงและฟีเจอร์ขึ้นกับสภาพแวดล้อม

## Prompt ขั้นสูงที่พร้อมใช้

> เป้าหมาย: แก้ปัญหาหน้า checkout คำนวณส่วนลดซ้ำ บริบท: ตรวจไฟล์ใน src/checkout และ tests/checkout ข้อจำกัด: รักษา public API เดิม ห้ามแก้ข้อมูล migration และอย่าแตะไฟล์นอกขอบเขต เสร็จเมื่อ: มี test ที่ทำให้บั๊กเดิมเกิดซ้ำ test ใหม่ผ่าน test เดิมผ่าน และสรุปสาเหตุพร้อมไฟล์ที่แก้

Prompt นี้มี Goal, Context, Constraints และ Done when ซึ่งช่วยให้ Agent ตรวจผลได้ ไม่ใช่หยุดหลังสร้างโค้ด

## ทำให้ความสามารถใช้ซ้ำ

เก็บกฎ repository ใน AGENTS.md ใช้ config สำหรับค่าการทำงาน ใช้ skill กับ workflow ที่เกิดซ้ำ และเชื่อมข้อมูลภายนอกผ่าน MCP หรือ connector เท่าที่จำเป็น ให้สิทธิ์ต่ำสุดก่อน แล้วขยายเฉพาะงานที่ไว้ใจได้

## Quality Gate

อ่าน diff รัน test ตรวจไฟล์ที่ไม่ได้ตั้งใจเปลี่ยน และอย่าให้ Agent deploy, ลบข้อมูล หรือแก้ระบบจริงโดยไม่มี approval งานสำเร็จเมื่อพฤติกรรมเปลี่ยนตามเป้าหมายและหลักฐานตรวจผ่าน ไม่ใช่เพียง Agent บอกว่าเสร็จ

แหล่งข้อมูลทางการ: https://learn.chatgpt.com/guides/best-practices และ https://learn.chatgpt.com/docs/quickstart
